Next to it runs the Bayes-optimal estimator, computed exactly. Both predict the next state before it happens.

What you are looking at

The transformer was trained on many random systems, then frozen. It can only adapt through its context window, the way a language model picks up a pattern from a prompt. While data are scarce it is as good as the exact Bayes-optimal estimator; with more context it levels off slightly above it, 1.59× the Bayes excess risk on average.

The middle panel is the paper's functional test: the derivative of the prediction with respect to the newest input is the parameter estimate the network is effectively using, and it tracks the Bayes estimate. The paper then shows where the evidence for that estimate is stored: in the attention keys and values of the last two blocks, not in the residual stream. Swapping only those keys and values with another episode's moves 91–94% of the behaviour.
